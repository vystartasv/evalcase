# Contributing

1. Install Bun 1.3.14 or newer.
2. Run `bun install --frozen-lockfile`.
3. Run `bun run verify`.
4. Keep changes dependency-free at runtime and add a regression test for contract or diagnostic changes.

Use conventional commit prefixes such as `feat:`, `fix:`, `docs:`, and `test:`. Do not include API keys, customer data, or generated output in commits.
